# Échanges entre joueurs — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** mise en relation entre joueurs réunionnais : liste « À échanger », correspondances avec la wishlist, demandes avec contact dévoilé à l'acceptation, notifications e-mail.

**Architecture:** un module de domaine `app/trades.py` (requêtes de correspondance, recalage des offres, machine à états, sérialiseurs) consommé par un routeur mince `app/routers/trades.py` ; réglages via `PATCH /api/auth/me` ; côté web, un module d'appels `src/trades.js`, une page `TradesView.vue` et trois points d'entrée (fiche carte, lots de la fiche, profil).

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic (migration manuelle), pytest (SQLite mémoire, FK non appliquées) ; Vue 3, Vitest, charte Forge noxienne (`src/ui/`).

**Spec:** `docs/superpowers/specs/2026-10-08-echanges-design.md` ; contrat `riftarium/docs/echanges.md` (source de vérité des formes et codes).

## Global Constraints

- Zones : exactement `nord`, `sud`, `est`, `ouest` ; contact ≤ 80 caractères ; message ≤ 280 caractères.
- `trade_enabled` faux par défaut, `notify_trades` vrai par défaut.
- 10 demandes `pending` sortantes au plus ; une seule `pending` par (demandeur, offre).
- Contact présent dans `RequestOut` seulement si `status ∈ {accepted, done}` ; jamais dans un e-mail.
- E-mail « nouvelle demande » : au plus un par couple (demandeur → propriétaire) par 24 h.
- `limit_trades` : 30 écritures / min / IP.
- Aucune mention de prix ou de vente dans l'interface.
- SQLite de test n'applique pas les FK : toute cascade doit aussi être faite par le code (`delete_user_account`, recalage des offres).
- Textes, commentaires, commits en français ; identifiants en anglais. Commits `API : …`, `Web : …`.
- Web : aucun style de composant dans une vue ; chaque classe de gabarit a une règle (`cssCoverage.spec.js`).

## Review Focus

1. **Lot fusionné ou reclassé** (PATCH qui change l'état d'un lot vers un lot existant) : l'offre du lot supprimé disparaît, ses demandes `pending` passent `cancelled` — test `test_offer_dropped_when_lot_merged`.
2. **Quantité de lot baissée sous l'offre via bulk** (`POST /collection/bulk qty_delta=-2`) : l'offre est ramenée — test `test_offer_clamped_by_bulk`.
3. **Compte qui se désinscrit avec des demandes en cours des deux côtés** : `pending` annulées, `accepted` conservées avec contact — test `test_disable_cancels_pending_keeps_accepted`.
4. **Suppression de compte partie d'une demande acceptée** : l'autre partie ne plante pas en listant ses demandes (la demande disparaît) — test `test_account_deletion_removes_trades`.
5. **Activation avec contact fait d'espaces** : 422 — test `test_enable_requires_zone_and_contact`.

```python
    id: Mapped[int] = mapped_column(primary_key=True)

    )

    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=utcnow)

class TradeRequest(Base):
    """Demande d'un joueur sur l'offre d'un autre. Carte, état et langue sont copiés :
    la demande reste lisible quand l'offre disparaît."""

    __tablename__ = "trade_requests"
    __table_args__ = (
        CheckConstraint("requester_id <> owner_id", name="ck_trade_request_not_self"),
        Index(
            "uq_trade_request_pending",
            "requester_id",
            "trade_offer_id",
            unique=True,
            sqlite_where=text("status = 'pending'"),
            postgresql_where=text("status = 'pending'"),
        ),
    )

    id: Mapped[int] = mapped_column(primary_key=True)
    requester_id: Mapped[int] = mapped_column(ForeignKey("users.id", ondelete="CASCADE"), index=True)
    owner_id: Mapped[int] = mapped_column(ForeignKey("users.id", ondelete="CASCADE"), index=True)
    trade_offer_id: Mapped[int | None] = mapped_column(
        ForeignKey("trade_offers.id", ondelete="SET NULL"), nullable=True, index=True
    )
    card_id: Mapped[str] = mapped_column(ForeignKey("cards.id"))
    condition: Mapped[str] = mapped_column(String(8))
    lang: Mapped[str] = mapped_column(String(8))
    message: Mapped[str] = mapped_column(String(280), default="")
    status: Mapped[str] = mapped_column(String(16), default="pending", index=True)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=utcnow)
    responded_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    done_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)

    card: Mapped[Card] = relationship(lazy="joined")
```
